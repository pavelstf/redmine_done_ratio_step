# Done Ratio Step 1.0.7 за GCR staging

Целева среда: GCR Redmine 6.1.2 staging. Пакетът е кандидат за проверка на текущия процент при една избрана задача.

- Архив: `redmine_done_ratio_step-1.0.7-staging-20261124.zip`
- Размер: 9 977 байта. Съдържа 9 файла в папка `redmine_done_ratio_step/`.
- SHA-256 на ZIP: `1b10c111e283e1e6b884c30681752ed8f4f2842b8875c5f839726003216184d8`
- SHA-256 на JavaScript: `8189a87085bca16e45c6e48a2167c7a5d47831e4b5882d505abef8632a4601b9`

Качи ZIP файла и `staging-1.0.7.sh` в `/home/gcrbgcaa/redminestaging/plugins/`. В SSH или cPanel Terminal като `gcrbgcaa`:

```bash
clear
bash /home/gcrbgcaa/redminestaging/plugins/staging-1.0.7.sh install
```

Скриптът очаква вече инсталиран плъгин. Архивира текущия код, обновява публичните JavaScript файлове, проверява версията през Rails и заявява рестарт на Passenger. `SUCCESS` изисква съвпадение на инсталирания JavaScript и HTTP отговора по SHA-256. Няма миграции или нови gem зависимости.

След `SUCCESS` презареди с **Ctrl+F5** при включено **Disable cache**. Изпълни проверките върху тестови задачи:

| Случай | Очакван резултат |
| --- | --- |
| Една задача със записани **17%**, стъпка на плъгина **5%**. | **% Done** показва **22 опции**. `17%` е веднъж, маркиран и неактивен между `15%` и `20%`. |
| Една задача със записани **15%**, интервал на Redmine **10%**, стъпка на плъгина **5%**. | **% Done** показва **21 опции**. Единственият `15%` е маркиран и неактивен. |
| Една задача на **40%** със стъпка **5%**. | Има **21 опции** и един неактивен `40%` на девета позиция. |
| Tracker филтър. Смени процента на тестовата задача и отвори менюто отново. | **Status** показва статуси. Промяната записва правилното поле, връща към филтрирания списък, а новият текущ процент се маркира. |
| Направи множествен избор и провери изцяло неактивно меню. | Плъгинът не добавя фиктивен избран процент и не активира забранено действие. |

За връщане на предишния пакет:

```bash
clear
bash /home/gcrbgcaa/redminestaging/plugins/staging-1.0.7.sh rollback
```

Rollback възстановява конкретния backup от обновяването до 1.0.7, обновява JavaScript на възстановената версия и проверява HTTP отговора. Backup-ите остават в staging `plugins/`. Логът е `/home/gcrbgcaa/redminestaging/log/production.log`.
